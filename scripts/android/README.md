# PixelのHTTP ShortcutsからFlowLogへ登録

既存の `FlowLogへ`、`Inbox`、`FlowLog写真` のエクスポートをMac上で修正する。接続先を `https://flowlog.jp/api/capture` と `/api/capture-image` に変更し、元のID・名前・認証情報・共有変数・本文・写真のsourceを維持する。

エクスポートには認証情報が含まれる。原本・修正版・端末から再取得した確認用ファイルは、Git管理外の権限を制限した場所へ保存する。Webエディターにはアップロードしない。

```sh
python3 scripts/android/patch_http_shortcuts.py /private/path/original.zip /private/path/fixed.zip
node scripts/android/test_http_shortcuts.mjs
```

修正版を端末のHTTP Shortcutsへファイルインポートする。同じショートカットIDで更新される。インポート後に再エクスポートし、接続先・ヘッダー・スクリプト以外の設定が保たれたことを照合する。端末へ一時配置した認証情報入りZIPは、バックアップと読み戻しの確認後に削除する。

投稿前に内容別のIDを固定変数へ保存し、`Idempotency-Key` ヘッダーへ設定する。通信失敗や不明な応答の後は、同じ入力の再実行でそのIDを使う。成功確認後の60秒間も同じIDを使うため、短時間で繰り返し起動しても同じ投稿になる。成功から60秒以上たった後の実行は新しい投稿として扱う。テキストは入力、写真はファイル形式と内容のハッシュで区別する。未解決の記録は自動で破棄せず、保存領域が不足する場合は送信を止める。

2026-10-31の実機確認では、共有とInboxから架空URLを本番へ送り、保存を読み戻した。共有の連続再実行で1件だけになり、試験URLを削除した。日記生成ジョブは変化していない。写真は実設定から複製した一時ショートカットとMacの試験サーバーで確認し、選択したPNGのバイト列・形式・同じ画像の再実行時のIDが一致した。一時ショートカット・変数・画像・試験接続は削除した。本番への写真投稿はこの確認では行っていない。

端末解除はVaultの既存 `android_device_ui.py` に任せる。この修正スクリプトはPINやKeychainの内容を扱わない。
